# Сайт-портфолио Kreiss 🎨

Современный сайт-портфолио дизайнера с интеграцией Telegram бота для получения заявок.

## 🚀 Быстрый старт

1. Откройте `index.html` в браузере
2. Настройте Telegram бот (инструкция ниже)

## 📱 Настройка Telegram бота

### Шаг 1: Создайте бота

1. Откройте Telegram и найдите [@BotFather](https://t.me/BotFather)
2. Отправьте команду `/newbot`
3. Придумайте имя бота (например: "Kreiss Portfolio Bot")
4. Придумайте username бота (должен заканчиваться на "bot", например: "kreiss_portfolio_bot")
5. **BotFather пришлёт вам токен** — скопируйте его

Токен выглядит примерно так: `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz`

### Шаг 2: Получите свой Chat ID

1. Найдите в Telegram бота [@userinfobot](https://t.me/userinfobot)
2. Нажмите "Start" или отправьте `/start`
3. Бот пришлёт ваш **Chat ID** (это числовой ID, например: `123456789`)

### Шаг 3: Настройте config.js

Откройте файл `config.js` и вставьте ваши данные:

```javascript
const TELEGRAM_CONFIG = {
    // Вставьте токен от @BotFather
    BOT_TOKEN: '1234567890:ABCdefGHIjklMNOpqrsTUVwxyz',
    
    // Вставьте ваш chat_id от @userinfobot
    CHAT_ID: '123456789'
};
```

### Шаг 4: Запустите бота

1. Найдите вашего бота в Telegram по username
2. Нажмите "Start" или отправьте `/start`
3. Готово! Теперь все заявки с сайта будут приходить вам в Telegram

## ✅ Проверка работы

1. Откройте сайт в браузере
2. Заполните форму контактов
3. Нажмите "Отправить сообщение"
4. Проверьте Telegram — должно прийти уведомление о новой заявке

## 📋 Что получаете в Telegram

Когда кто-то оставляет заявку, вам приходит сообщение с:
- 👤 Именем клиента
- 📧 Email адресом
- 💬 Текстом сообщения
- ⏰ Временем отправки

## ⚠️ Важно

- Не делитесь токеном бота с другими людьми
- Храните `config.js` в безопасности
- Если токен утёк — создайте нового бота через @BotFather

## 🔧 Дополнительные настройки

### Изменить цветовую схему

Откройте `styles.css` и измените переменные в `:root`:

```css
:root {
    --primary-color: #6C5CE7;      /* Основной цвет */
    --secondary-color: #A29BFE;    /* Дополнительный цвет */
    --dark-color: #2D3436;         /* Тёмный цвет */
}
```

### Добавить свои изображения

Замените блоки `.portfolio-placeholder` в `index.html` на реальные изображения:

```html
<div class="portfolio-image">
    <img src="путь/к/изображению.jpg" alt="Описание">
</div>
```
